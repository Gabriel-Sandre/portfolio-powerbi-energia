# ferramentas

`pbip.py` gera projetos do Power BI no formato **PBIP** (modelo em TMDL + relatório em PBIR) a partir de
listas de tabelas, colunas, consultas M, medidas DAX e visuais. É usada pelo `criar_pbip.py` de cada projeto,
para que consultas e medidas tenham uma fonte única (os arquivos `.pq` e `.dax`).

`TemaEnergiaRJ.json` é o tema de cores aplicado aos três painéis.
